# Changelog

## 1.3.0

- Improved the mobile hero layout and CTA stacking.
- Reduced standings table density on small screens.

## 1.2.0

- Added unit tests for data transforms and cache helpers.
- Added CI workflow for build and test checks.

## 1.1.0

- Added a 24h `localStorage` fallback cache with manual refresh.
- Clarified empty states across the public pages.

## 1.0.0

- Public site only: home, calendar, results, standings, teams, news.
- Removed the admin/login/CMS placeholder from the public UI.
- Added a local fallback cache in `localStorage` for the last successful API load.
- Hardened the static server and added automated smoke tests.
- Improved mobile layout and keyboard focus states.
